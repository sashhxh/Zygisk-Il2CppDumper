# Claude Pet 🐾

Маленький персонаж (Claude), который **ходит по экрану Android поверх всех приложений**.
Его можно перетаскивать пальцем, а по тапу открывается чат — персонаж отвечает
через Anthropic Messages API.

> Это личный «питомец» для рабочего стола. Это не официальное приложение Anthropic.

## Что умеет

- Гуляет по экрану поверх других приложений (системный оверлей).
- Перетаскивается пальцем, показывает реплики в «облачке».
- По тапу открывается мини-чат; ответы приходят от Claude (нужен API-ключ).

## Как получить APK (автосборка)

APK собирается автоматически через GitHub Actions:

1. Открой репозиторий на GitHub → вкладка **Actions**.
2. Выбери workflow **Build Claude Pet APK** (запускается при изменениях в `claude-pet/`,
   либо вручную кнопкой **Run workflow**).
3. После зелёной галочки открой запуск → раздел **Artifacts** → скачай
   `claude-pet-debug-apk`.
4. Распакуй zip — внутри `app-debug.apk`.

## Установка на телефон

1. Перекинь `app-debug.apk` на телефон.
2. Открой файл, разреши установку из этого источника.
3. Запусти приложение **Claude Pet**.
4. Нажми **«Разрешить показ поверх окон»** и включи разрешение.
5. (Для чата) вставь API-ключ с https://console.anthropic.com и нажми **Сохранить**.
6. Нажми **«Запустить питомца»** и сверни приложение — Claude пойдёт гулять по экрану.

## Про API-ключ

- Чат работает через твой **личный ключ Anthropic** (отдельный баланс на
  console.anthropic.com). Подписка на приложение Claude тут **не** подходит.
- Ключ хранится только на телефоне и шлётся напрямую в `api.anthropic.com`.
- Без ключа персонаж всё равно ходит и реагирует — просто не отвечает в чате.
- Модель по умолчанию `claude-opus-5-5`. Дешевле — поставь `claude-haiku-5-5`
  в поле «Модель».

## Сборка вручную (Android Studio)

Открой папку `claude-pet/` как проект в Android Studio и нажми **Run**, либо в
терминале:

```bash
cd claude-pet
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

## Стек

- Kotlin, без внешних зависимостей (только Android SDK).
- Оверлей: `WindowManager` + `TYPE_APPLICATION_OVERLAY`, foreground-сервис.
- Сеть: `HttpURLConnection` + `org.json`, Anthropic Messages API.
- minSdk 26, targetSdk 34.
