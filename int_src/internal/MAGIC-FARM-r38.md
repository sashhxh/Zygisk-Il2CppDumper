# Auto Tool при подходе к ресурсу r38

Auto Run удалён из меню и исполнения. Код больше не формирует движение, не подменяет направление джойстика и не включает спринт. Вместо него в World → Resources находится переключатель Auto Tool.

Auto Tool работает независимо от Magic Farm и Resource ESP. Игрок подходит сам; выбирается ближайший живой ресурс отмеченного типа внутри Farm / Tool Distance. Для дерева берётся топор, для камня, железа и серы — кирка. Направление взгляда и ручная ходьба не ограничивают выбор. Ресурс за пределами этого радиуса не вызывает смену инструмента. Если инструмента для ближайшего ресурса нет, более далёкий ресурс не подменяет цель.

Из инвентаря, панели и рюкзака выбирается исправный инструмент с приоритетом мега → обычный → каменный. При равном классе уже взятый предмет сохраняется. Используется прежнее штатное событие экипировки; добыча ждёт фактического появления выбранного Item в FPTool. Инвентарь сканируется не чаще четырёх раз в секунду, повторные запросы экипировки ограничены одним в секунду. Меню приостанавливает смену предмета.

Для автоматической добычи дополнительно нужен Magic Farm. Подготовка нового инструмента и выбор крестика/свечения сохранены. Настройки сохраняются как EXTRAS_V3; EXTRAS_V2 с включённым Auto Run загружается с включённым Auto Tool, без движения. EXTRAS_V1 загружается с выключенным Auto Tool.

Проверки охватывают выбор ближайшего дерева/руды, границу расстояния, обычные/мегаинструменты, износ, ограничение повторных запросов, совместимость настроек и меню. Сборка ARM64 и launcher проверяются отдельно. На Android-устройстве и игровом сервере эта версия не проверена.
