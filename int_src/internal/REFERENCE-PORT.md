# Перенос интерфейса xvcen: r42

Это **частичный перенос**, а не подтверждённая копия всего чита 1:1.
Ресурсы извлечены из предоставленного `xvcen.sh`, интерфейс восстановлен
по его ARM64-коду и подключён к функциям `internal-r40-source (1).zip`.
Образец анализировался как данные; его исполняемый код не запускался.

## Что перенесено

- Все семь встроенных PNG: шесть иконок разделов и лист анимации аватара.
  Разрешение, цвета, прозрачность и пиксели сохранены без уменьшения.
- Оба найденных встроенных TTF, включая шрифт интерфейса и ProggyClean.
  Для отсутствующих в оригинальном TTF кириллических глифов используется
  существующий шрифт исходника; оригинальные латинские глифы сохраняются.
- ImGui и Vulkan backend обновлены с 1.91.9 до оригинальной версии 1.92.9b.
  Восстановлены параметры ProggyForever: PixelSnapH, oversampling 1×1,
  ExtraSizeScale 1.015, GlyphOffset.y 0.40625, ImplicitRefSize. Глифы теперь
  растеризуются отдельно для запрошенных размеров текста, как в образце.
- 126 пар английских/русских надписей из таблиц образца.
- Каркас окна 840×720, панель 265 пикселей, шесть вкладок, иконки 52×52,
  светлая/тёмная тема, переключатели, цветовые поля, прокрутка касанием,
  индикатор активной вкладки с пружинной анимацией, аватар из 74 кадров
  с частотой 30 кадров/с. Окно уменьшается, когда не помещается на экране.
- Верхний островок Enemies/Bots: исходные размеры и отступы, переключение
  меню по нажатию, обводка и импульс, задержка принятия числа 50 мс,
  критически затухающая пружина частотой 11 и вертикальная смена цифр.
  FPS раскрывается отдельной капсулой с ease-out-back; его число берётся
  из ImGuiIO.Framerate, тогда как образец запрашивает частоту экрана.
- Уведомления перенесены в правый верхний угол: пружины появления,
  изменения ширины и полосы времени, смена текста через затухание,
  очередь сообщений, срок 2.6 с, отдельные цвета ON/OFF.
- Анимация открытия/закрытия 0.4 с со smoothstep и изгибом к нижней точке.
  Восстановлены стадии деформации из функций образца 0xc4b80/0xc5920.
  В новой реализации изгиб применяется к разделённой на полосы геометрии
  ImGui; оригинал деформирует предварительно отрисованную текстуру окна.
  Качество фильтрации этих двух способов ещё требует сравнения на телефоне.
- Переходы содержимого вкладок с пружинным сдвигом 50 пикселей и затуханием;
  пружины ползунков с исходными коэффициентами активного/пассивного состояния.
- Вместо стандартного ImGui ColorPicker — выезжающая панель с оригинальными
  28 RGBA-цветами, сеткой 7×4 и пружинной рамкой выбранного цвета.
- Стиль ESP: углы длиной `clamp(min(w,h)*0.28, 2, 30)`, три слоя линий,
  тень и два прохода текста, компактная дистанция `125m`, полоска здоровья,
  трассеры с наконечником, ромбы и цвета ресурсных меток.
- Новые параметры внешнего вида сохраняются в дополнительной записи
  `REFERENCE_UI_V1` после старых настроек. Старые конфиги продолжают читаться.
- Функции исходника, включая Chams, Magic Farm и положение оружия,
  доступны в адаптированных разделах нового меню.

SHA-256 образца:
`016ff453d7f803f0a256cdb5cd7ca736028842389b20e7b5ba06b2662670a983`.
Размеры, адреса и SHA-256 извлечённых изображений/шрифтов находятся в
`jni/reference_assets/manifest.json`. PNG проверены по CRC каждого блока,
TTF после stb-распаковки — по Adler-32. Проверка на хосте дополнительно
сравнивает каждый RGBA-пиксель всех семи изображений с содержимым атласа.

## Что ещё требуется для полного 1:1

1. Сверить скриншоты или запись **всех вкладок и всплывающих окон** оригинала
   при известном разрешении. Текущие PNG-превью — рендер нового кода на хосте,
   а не скриншоты работающего чита на Android.
2. Восстановить исходные диалоги и раскладку страниц целиком: менеджер
   нескольких конфигов, About, выбор Touch/Memory/Silent, вложенные настройки
   костей/режимов. Сейчас страницы адаптированы к имеющимся функциям исходника.
   Цветовая панель восстановлена; затемнение под ней пока не воспроизводит
   фильтрацию оригинального фона через промежуточную текстуру.
3. Для ESP ботов, ящиков и животных нужен отсутствующий в этом исходнике сбор
   данных. Работающие переключатели этих возможностей не имитируются.
4. Проверить получение имён и здоровья на нужной версии игры. Имена читаются
   только из полей, которые проходят проверку класса `String`, границ и UTF-16;
   при неуспехе подпись не рисуется. Здоровье использует уже имеющуюся цепочку
   исходника и шкалу 0–100. Максимальное здоровье, отличающееся от 100, требует
   отдельной проверки. Стрелки пока используют доступные проекции перед камерой;
   объекты за камерой исходник в снимок не передаёт.
5. Проверить Android, производительность и графику на устройстве. Версии ImGui
   и параметры оригинальных шрифтов теперь совпадают, но попиксельного
   сравнения с работающим оригиналом и замеров времени кадров ещё нет.
   Кириллический запасной шрифт и источник FPS также требуют сверки.

Атлас RGBA размером 4096×4096 занимает 64 МиБ на CPU и ещё одну текстуру на GPU.
Это позволяет сохранить оригинальные изображения, но расход памяти нужно
проверить вместе с игрой на телефоне.

## Сборка

Использован Android NDK r27c, ABI `arm64-v8a`, Android API 24.
Из каталога, содержащего `internal`:

```sh
ANDROID_NDK_HOME=/путь/android-ndk-r27c sh internal/build.sh -j4
python internal/package_launcher.py --output start-reference-ui.sh
```

Готовые файлы: `internal/libs/arm64-v8a/libcfesp.so` и `cfinject`.
Лоадер использует существующий механизм запуска исходного проекта.

Повторное извлечение ресурсов из исходного образца:

```sh
python internal/tools/extract_reference.py xvcen.sh internal/jni/reference_assets
python internal/tools/embed_reference_assets.py
```

Вторая команда требует Pillow; для обычной сборки он не нужен, сгенерированные
заголовки уже включены. Оригинальное меню r40 сохранено в `jni/menu_r40.h`.

## Проверки

```sh
python internal/tests/run_menu_tests.py --world-preview /tmp/menu
python internal/tests/run_host_tests.py
python internal/tests/run_vulkan_tests.py --vulkan-include /путь/к/include
python internal/tests/run_vulkan_tests.py --reference-ui --vulkan-include /путь/к/include
```

Проверки меню используют ASan/UBSan, клики по настоящим виджетам, прокрутку,
переключение языка и темы, цветовые окна, закрытие/открытие и три разрешения.
Дополнительно проверяются задержка счётчиков, независимость критической
пружины от частоты кадров, разворот анимации меню, выбор точного цвета,
раскрытие FPS, смена очереди и закрытие уведомлений. Изображения сравниваются
с атласом до и после динамической загрузки глифов разных размеров.
Vulkan проверяется на программном драйвере с Khronos validation: 240 кадров,
восемь ориентаций, 48 кликов, UNORM/sRGB, потеря swapchain и ошибка выделения.
Цветная метка из атласа должна сохранить RGB 128/64/32 в обоих форматах —
для этого формат текстуры атласа выбирается по формату целевого изображения.
Вариант --reference-ui повторяет 240 кадров и проверки ориентаций с настоящими
ресурсами, вкладками, шрифтом, островком и деформацией меню, а не только
с диагностическими прямоугольниками.

Эти проверки не заменяют запуск на Android и не подтверждают видимость
или корректность игровых полей в конкретной версии Oxide.
