# Auto Tool: выбор слота панели r39

В r38 пользователь сообщил, что Auto Tool не берёт инструмент с панели быстрого доступа. Без состояния процесса точная причина отказа r38 не установлена. В r39 изменён путь для предметов на панели: читается тот же упорядоченный Hotbar.Kob (List<Slot>), который использует штатный Hotbar.cAG. Из Slot.KRV берётся текущая ячейка, а в запрос передаётся порядковый индекс в этом списке, не глобальный индекс ячейки инвентаря.

Сначала сканируется локальная панель, независимо от готовности общего kJF.Cells. Затем дополняются предметы из общего списка принадлежащих игроку ячеек. Повторные ячейки исключаются; общий список не затирает маршрут к слоту панели. Перед выбором проверяются соответствие индекса, Slot, ячейки и Item. Для панели вызывается Hotbar.cAG(index, true), чтобы выполнить весь штатный путь выбора и обновления панели. Сборка не подменяет Tryer/проверки самой игры. Для предметов вне панели сохранён прежний ChangeEquippedItem.

Открытие меню теперь сохраняет результат последней попытки, при этом экипировка остаётся приостановленной. Добавлены статусы недоступного инвентаря, пустого списка ячеек, отсутствия подходящего инструмента, изменения слота и отказа запроса. Строка Slots / Items / Tools помогает отличить ошибку чтения инвентаря от ошибки выбора предмета. В Android logcat раз в пять секунд выводится сводка сканирования, а при попытке — индекс слота и результат.

Устранено бессрочное ожидание при установленном EquippedItem без появления соответствующего FP-предмета. Для панели после трёх секунд разрешается повторный штатный выбор слота; уже взятый предмет повторно не выбирается. Обычная смена на другой инструмент начинается без этой задержки.

Автобег отсутствует. Выбор ближайшего ресурса внутри Farm / Tool Distance, приоритет мегаинструментов и подготовка добычи сохранены. Для проверки нужно запустить новый start.sh, включить Auto Tool, закрыть меню и подойти к дереву/руде с соответствующим инструментом на панели. При повторении ошибки открыть меню и записать Tool и Slots / Items / Tools.

Host-тесты покрывают независимую панель без общего списка, пустые слоты, различие глобального и локального индексов, изменение Item, перестановку слотов, повреждённую длину списка и сохранение маршрута при повторном сканировании. Android-устройство и результат на сервере не проверены.
