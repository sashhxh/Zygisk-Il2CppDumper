# Auto Run / автоматический инструмент r37

При включённом Auto Run ближайший ресурс выбирается среди отмеченных в меню типов, для которых у игрока есть подходящий исправный инструмент. Для дерева нужен топор, для камня, железа и серы — кирка. Просматриваются ячейки локального инвентаря, панели быстрого доступа и рюкзака; лут и слоты экипировки исключены. Сломанные инструменты и пустые стопки исключены.

Мегаинструмент предпочитается обычному, обычный — каменному. При одинаковом классе остаётся уже взятый инструмент; если подходящий предмет ещё не в руках, выбирается самый целый. Используется штатное событие ChangeEquippedItem(Item, false) с тем же уведомлением о ячейке, что и у панели быстрого доступа. Предметы не создаются, их количество и контейнеры не переписываются. Движение и добыча ждут фактической смены FPTool на выбранный Item. Повторные запросы ограничены одним в секунду; меню и ручное управление приостанавливают выбор.

Дополнительный переключатель не нужен: автовыбор работает вместе с Auto Run. Для автоматической добычи также включите Magic Farm. Состояние Run показывает ожидание смены инструмента, отсутствие инструментов или недоступность экипировки. Настройки остаются EXTRAS_V2.

Подготовка нового инструмента без ручного удара и выбор крестика/свечения сохранены из r36. Автоматический маршрут использует прежнее локальное обходное движение, без глобального поиска пути.

Проверено: сборка ARM64 с NDK r27d, host-тесты выбора/износа/ограничения запросов, меню и launcher, соответствие 116 сигнатур исходному libil2cpp.so. Устройство и получение ресурсов на сервере не проверены. На устройстве нужно проверить выбор предмета из каждого поддержанного контейнера, переход руда → дерево, мегаинструменты, поломку/удаление инструмента и остановку при ручном управлении.
